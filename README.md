# PathFinder AI - Career Assistant

An AI-powered career recommendation application built with React, Vite, and Tailwind CSS.

## Features
- **AI Career Roadmaps**: Personalized 5-step plans to reach your career goals.
- **Interview Prep**: Industry-specific questions and tips generated by AI.
- **Salary Insights**: Market-driven salary predictions based on education and experience.
- **Resume Tailoring**: Dynamic bullet point generation to highlight transferable skills.

## Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   - Create a `.env` file in the root directory.
   - Add your Gemini API key:
     ```env
     VITE_GEMINI_API_KEY=your_actual_api_key_here
     ```

3. **Run for Development**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```

## Tech Stack
- **Frontend**: React 19, Vite 7
- **Styling**: Tailwind CSS 4 (using the @tailwindcss/vite plugin)
- **Icons**: Lucide React
- **AI**: Google Gemini API
